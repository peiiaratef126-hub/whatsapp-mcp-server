WhatsApp MCP Server

Connect personal WhatsApp accounts to LLMs (Claude Desktop, Cursor, etc.) via whatsmeow and FastMCP with 22 built-in tools.

Architecture & Deployment Overview

This system uses a decoupled, two-tier architecture designed for privacy, local session isolation, and end-to-end security:

Go WhatsApp Bridge
whatsmeow (WebSocket)

Persistent multi-device client with local SQLite store and 127.0.0.1 HTTP API.

Python MCP Server
FastMCP (STDIO)

Exposes 22 typed tools over STDIO to Claude Desktop with confirmation gating.

Vercel Deployment Context: Vercel hosts this web documentation and status portal. The underlying WhatsApp connection requires a persistent WebSocket and local SQLite database running on your local machine or a dedicated VPS.

Claude Desktop Configuration

Add this configuration to your claude_desktop_config.json:

{
  "mcpServers": {
    "whatsapp": {
      "command": "python",
      "args": [
        "-m", "whatsapp_mcp_server.main"
      ],
      "env": {
        "WHATSAPP_BRIDGE_URL": "http://127.0.0.1:8080",
        "SENTRY_DSN": ""
      }
    }
  }
}
